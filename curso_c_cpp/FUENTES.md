# Fuentes y bibliografía

Este curso se apoya en material de referencia reconocido. Aquí están las fuentes usadas y
recomendadas para profundizar. **Nada de este curso copia texto de esas obras**: son
explicaciones propias; las fuentes se citan como referencia y lectura ampliada.

## Libros — C

- **Kernighan, B. W. & Ritchie, D. M. — *The C Programming Language* (2.ª ed., 1988).**
  El libro clásico, escrito por los creadores del lenguaje ("K&R"). Conciso y preciso; la
  referencia histórica de C. (Cubre C89/ANSI C.)
- **King, K. N. — *C Programming: A Modern Approach* (2.ª ed., 2008).**
  Muy didáctico y completo, ideal para aprender C moderno con muchos ejercicios. Es la principal
  referencia pedagógica de la pista de C.
- **Prata, S. — *C Primer Plus* (6.ª ed., 2013).** Otra introducción amplia y accesible.
- **Griffiths, D. & Griffiths, D. — *Head First C* (2012).** Enfoque visual, bueno para
  principiantes.

## Libros — C++

- **Stroustrup, B. — *The C++ Programming Language* (4.ª ed., 2013).**
  Escrito por el creador de C++. Es la referencia completa (cubre C++11).
- **Stroustrup, B. — *A Tour of C++* (2.ª/3.ª ed.).** Versión breve y moderna del anterior;
  excelente para ver "todo C++" de forma condensada (C++17/C++20).
- **Stroustrup, B. — *Programming: Principles and Practice Using C++* (2.ª ed., 2014).**
  Pensado para aprender a programar **desde cero** usando C++. Base pedagógica de la pista C++.
- **Lippman, S., Lajoie, J. & Moo, B. — *C++ Primer* (5.ª ed., 2012).**
  Muy recomendado para aprender C++ moderno (C++11) con profundidad.
- **Meyers, S. — *Effective C++* (3.ª ed.) y *Effective Modern C++* (2014).**
  Colecciones de "buenas prácticas". Para cuando ya domines lo básico.

## Sitios web

- **cppreference.com** — https://en.cppreference.com/ (y https://es.cppreference.com/)
  La **referencia técnica** más fiable de C y C++ (biblioteca estándar, lenguaje). Consulta
  obligada para detalles exactos de funciones y tipos.
- **cplusplus.com** — https://cplusplus.com/ Tutoriales y referencia de la biblioteca estándar,
  con ejemplos claros.
- **learncpp.com** — https://www.learncpp.com/ Tutorial gratuito, extenso y muy bien explicado de
  C++ moderno. Altamente recomendado como complemento de la pista C++.
- **Beej's Guide to C Programming** — https://beej.us/guide/bgc/ Guía gratuita, amena y sólida
  de C.
- **GeeksforGeeks — C** (https://www.geeksforgeeks.org/c-programming-language/) **y C++**
  (https://www.geeksforgeeks.org/c-plus-plus/) Artículos y ejemplos puntuales por tema.
- **ISO C++ (isocpp.org)** — https://isocpp.org/ Sitio oficial de la comunidad C++, con las
  *Core Guidelines* (https://isocpp.github.io/CppCoreGuidelines/): buenas prácticas modernas.
- **Compiler Explorer (godbolt.org)** — https://godbolt.org/ Para ver en qué se traduce tu código
  y probar fragmentos en el navegador.

## Estándares oficiales (para referencia exacta)

- **C:** ISO/IEC 9899. Versiones: **C89/C90** (ANSI C), **C99**, **C11** (la que usamos), **C17**,
  **C23**. Borradores públicos: https://www.open-std.org/jtc1/sc22/wg14/
- **C++:** ISO/IEC 14882. Versiones: **C++98/03**, **C++11**, **C++14**, **C++17** (la que
  usamos), **C++20**, **C++23**. Borradores públicos: https://www.open-std.org/jtc1/sc22/wg21/

> Los estándares son documentos técnicos (de pago la versión final, gratis los borradores casi
> idénticos). No son para aprender, sino para resolver dudas exactas de comportamiento.

## Herramientas

- **GCC/G++** — https://gcc.gnu.org/ · **Clang/LLVM** — https://clang.llvm.org/
- **GDB** (depurador) — https://www.sourceware.org/gdb/
- **Valgrind** (errores de memoria) — https://valgrind.org/
- **CMake** / **Make** — sistemas de construcción para proyectos con muchos archivos.

## Cómo se citan las fuentes en las lecciones

Al final de cada lección hay una sección **"Para profundizar"** que apunta a los capítulos o
páginas concretas de estas fuentes relacionados con el tema. Úsalas cuando quieras ir más allá de
lo que el curso explica.
