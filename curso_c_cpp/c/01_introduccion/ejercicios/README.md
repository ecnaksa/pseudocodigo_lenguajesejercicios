# Ejercicios — Lección 01

Resuélvelos **tú** antes de mirar [`soluciones/`](soluciones). Compila cada uno con
`gcc -std=c11 -Wall -Wextra archivo.c -o prog && ./prog`.

1. **Tu saludo.** Escribe un programa que imprima `Hola, me llamo <tu nombre>` seguido de un
   salto de línea. → [`soluciones/ej1_saludo.c`](soluciones/ej1_saludo.c)

2. **Tarjeta de presentación.** Imprime en tres líneas tu nombre, tu ciudad y tu meta al aprender
   a programar. → [`soluciones/ej2_tarjeta.c`](soluciones/ej2_tarjeta.c)

3. **Tabla con tabulaciones.** Usando `\t`, imprime una mini tabla así (las columnas alineadas
   con tabulación):
   ```
   Producto	Precio
   Cafe	3
   Pan	1
   ```
   → [`soluciones/ej3_tabla.c`](soluciones/ej3_tabla.c)

4. **Arte ASCII.** Imprime un cuadrado de 3x3 hecho con asteriscos:
   ```
   ***
   ***
   ***
   ```
   → [`soluciones/ej4_cuadrado.c`](soluciones/ej4_cuadrado.c)

5. **Reto.** Imprime esta ruta de archivo tal cual (fíjate en las barras invertidas):
   ```
   C:\Users\ana\prog
   ```
   Pista: recuerda cómo se escribe una barra invertida literal dentro de una cadena.
   → [`soluciones/ej5_ruta.c`](soluciones/ej5_ruta.c)
