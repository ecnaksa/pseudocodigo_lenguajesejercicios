# Ejercicios — Lección 02

1. **Datos personales.** Declara variables para tu edad (`int`), tu estatura en metros
   (`double`) y la inicial de tu nombre (`char`). Imprímelas con un texto descriptivo.
   → [`soluciones/ej1_datos.c`](soluciones/ej1_datos.c)

2. **Área del círculo.** Con `const double PI = 3.14159` y un radio fijo (por ejemplo `5.0`),
   calcula e imprime el área (`PI * radio * radio`). → [`soluciones/ej2_area.c`](soluciones/ej2_area.c)

3. **Promedio de tres enteros.** Declara tres `int`, súmalos y calcula su promedio **con
   decimales** (cuidado con la división entera: usa un casting a `double`).
   → [`soluciones/ej3_promedio.c`](soluciones/ej3_promedio.c)

4. **Explorando tamaños.** Imprime el `sizeof` de `int`, `long`, `float` y `double`, y también
   `INT_MAX`. → [`soluciones/ej4_tamanos.c`](soluciones/ej4_tamanos.c)

5. **Reto — carácter y código.** Declara un `char` con la letra `'Z'`. Imprímelo como carácter y
   como número (su código ASCII). Luego imprime el carácter cuyo código es `'Z' + 1`.
   → [`soluciones/ej5_ascii.c`](soluciones/ej5_ascii.c)
