# Ejercicios — Lección 03

1. **Suma de dos números.** Pide dos enteros y muestra su suma.
   → [`soluciones/ej1_suma.c`](soluciones/ej1_suma.c)

2. **Conversión de temperatura.** Pide una temperatura en Celsius (`double`) y muéstrala en
   Fahrenheit: `F = C * 9 / 5 + 32`. → [`soluciones/ej2_temperatura.c`](soluciones/ej2_temperatura.c)

3. **Datos con formato.** Pide un precio (`double`) y una cantidad (`int`), y muestra el total con
   2 decimales, alineando el resultado en un ancho de 10.
   → [`soluciones/ej3_total.c`](soluciones/ej3_total.c)

4. **Rectángulo.** Pide base y altura (enteros) y muestra el área y el perímetro.
   → [`soluciones/ej4_rectangulo.c`](soluciones/ej4_rectangulo.c)

5. **Reto — inicial y edad.** Pide la edad (`int`) y luego la inicial del nombre (`char`).
   Muestra ambas. (Recuerda el truco del `" %c"`.)
   → [`soluciones/ej5_inicial.c`](soluciones/ej5_inicial.c)
