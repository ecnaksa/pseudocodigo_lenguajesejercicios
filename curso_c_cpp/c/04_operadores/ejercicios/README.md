# Ejercicios — Lección 04

1. **Par o impar (sin condicionales aún).** Pide un entero y muestra `n % 2` (será 0 si es par, 1
   si es impar). → [`soluciones/ej1_par_residuo.c`](soluciones/ej1_par_residuo.c)

2. **Descomponer segundos.** Pide una cantidad de segundos y muestra cuántos minutos y segundos
   son (`min = s / 60`, `seg = s % 60`). → [`soluciones/ej2_segundos.c`](soluciones/ej2_segundos.c)

3. **Intercambio con una operación.** Pide dos enteros `a` y `b` e intercámbialos usando una
   variable temporal; muéstralos antes y después.
   → [`soluciones/ej3_intercambio.c`](soluciones/ej3_intercambio.c)

4. **Evaluar condiciones.** Pide una edad y muestra el valor (1/0) de: `edad >= 18`,
   `edad >= 18 && edad <= 65`, y `edad < 12 || edad > 65`.
   → [`soluciones/ej4_condiciones.c`](soluciones/ej4_condiciones.c)

5. **Reto — última cifra.** Pide un entero y muestra su **última cifra** (pista: `n % 10`) y el
   número **sin** la última cifra (`n / 10`).
   → [`soluciones/ej5_ultima_cifra.c`](soluciones/ej5_ultima_cifra.c)
