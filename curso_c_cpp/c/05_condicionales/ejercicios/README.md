# Ejercicios — Lección 05

1. **Mayor de dos.** Pide dos enteros y muestra el mayor (usa `if/else` o el ternario).
   → [`soluciones/ej1_mayor.c`](soluciones/ej1_mayor.c)

2. **Signo de un número.** Pide un entero y di si es **positivo**, **negativo** o **cero**.
   → [`soluciones/ej2_signo.c`](soluciones/ej2_signo.c)

3. **Año bisiesto.** Pide un año y di si es bisiesto. Es bisiesto si es divisible entre 4 **y** no
   entre 100, **o** si es divisible entre 400. → [`soluciones/ej3_bisiesto.c`](soluciones/ej3_bisiesto.c)

4. **Vocal o consonante.** Pide una letra minúscula y di si es vocal o consonante usando `switch`.
   → [`soluciones/ej4_vocal.c`](soluciones/ej4_vocal.c)

5. **Reto — calculadora.** Pide dos números y un operador (`+`, `-`, `*`, `/`) y muestra el
   resultado con `switch`. Cuida la división entre 0.
   → [`soluciones/ej5_calculadora.c`](soluciones/ej5_calculadora.c)
