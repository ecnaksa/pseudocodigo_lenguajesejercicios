# Ejercicios — Lección 06

1. **Cuenta regresiva.** Pide un número `n` y cuenta de `n` a 1, luego imprime `Despegue!`.
   → [`soluciones/ej1_regresiva.c`](soluciones/ej1_regresiva.c)

2. **Suma de 1 a N.** Pide `N` y calcula la suma `1 + 2 + ... + N`.
   → [`soluciones/ej2_suma.c`](soluciones/ej2_suma.c)

3. **Tabla de multiplicar.** Pide un número y muestra su tabla del 1 al 10.
   → [`soluciones/ej3_tabla.c`](soluciones/ej3_tabla.c)

4. **Factorial.** Pide `n` y calcula `n!` (`1*2*...*n`). Usa un tipo `long long` para no desbordar
   pronto. → [`soluciones/ej4_factorial.c`](soluciones/ej4_factorial.c)

5. **Reto — pirámide.** Pide una altura `h` e imprime una pirámide de asteriscos:
   ```
   *
   **
   ***
   ```
   (para `h = 3`). → [`soluciones/ej5_piramide.c`](soluciones/ej5_piramide.c)
