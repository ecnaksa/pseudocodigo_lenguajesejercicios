# Ejercicios — Lección 07

1. **Función cuadrado.** Escribe `int cuadrado(int n)` que devuelva `n*n`, y úsala en un bucle
   para imprimir los cuadrados del 1 al 5. → [`soluciones/ej1_cuadrado.c`](soluciones/ej1_cuadrado.c)

2. **Máximo de tres.** Escribe `int maximo3(int a, int b, int c)` que devuelva el mayor de tres
   enteros. → [`soluciones/ej2_maximo3.c`](soluciones/ej2_maximo3.c)

3. **¿Es primo?** Escribe `int esPrimo(int n)` que devuelva 1 si `n` es primo y 0 si no. Úsala para
   listar los primos del 2 al 30. → [`soluciones/ej3_primo.c`](soluciones/ej3_primo.c)

4. **Conversor.** Escribe `double aFahrenheit(double celsius)` y úsala para imprimir una tabla de
   0, 10, 20, 30 y 40 °C. → [`soluciones/ej4_conversor.c`](soluciones/ej4_conversor.c)

5. **Reto — potencia recursiva.** Escribe `long long potencia(int base, int exp)` que calcule
   `base^exp` **con recursión** (caso base: `exp == 0` devuelve 1).
   → [`soluciones/ej5_potencia.c`](soluciones/ej5_potencia.c)
