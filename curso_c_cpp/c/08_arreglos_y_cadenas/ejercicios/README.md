# Ejercicios — Lección 08

1. **Máximo y mínimo.** Declara un arreglo de 6 enteros con valores fijos y muestra su máximo y su
   mínimo. → [`soluciones/ej1_max_min.c`](soluciones/ej1_max_min.c)

2. **Invertir un arreglo.** Llena un arreglo de 5 enteros leídos y muéstralo al revés.
   → [`soluciones/ej2_invertir.c`](soluciones/ej2_invertir.c)

3. **Contar vocales.** Lee una palabra (`%s`) y cuenta cuántas vocales tiene, recorriéndola
   carácter a carácter hasta el `'\0'`. → [`soluciones/ej3_vocales.c`](soluciones/ej3_vocales.c)

4. **Promedio con función.** Escribe `double promedio(int arr[], int n)` y úsala con un arreglo de
   ejemplo. → [`soluciones/ej4_promedio.c`](soluciones/ej4_promedio.c)

5. **Reto — ¿palíndromo?** Lee una palabra y di si se lee igual al derecho y al revés (compara
   `s[i]` con `s[largo-1-i]`). → [`soluciones/ej5_palindromo.c`](soluciones/ej5_palindromo.c)
