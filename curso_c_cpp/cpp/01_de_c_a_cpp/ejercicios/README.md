# Ejercicios — Lección 01 (C++)

Compila con `g++ -std=c++17 -Wall -Wextra archivo.cpp -o prog`.

1. **Saludo.** Pide el nombre (`std::string`, o por ahora una palabra con `cin >>`) y saluda.
   → [`soluciones/ej1_saludo.cpp`](soluciones/ej1_saludo.cpp)

2. **Suma con cout/cin.** Pide dos enteros y muestra su suma, usando solo `cin` y `cout`.
   → [`soluciones/ej2_suma.cpp`](soluciones/ej2_suma.cpp)

3. **Área del rectángulo.** Pide base y altura (`double`) y muestra el área encadenando en un solo
   `cout`. → [`soluciones/ej3_area.cpp`](soluciones/ej3_area.cpp)

4. **Reto — mayor de dos.** Pide dos números y muestra el mayor, usando `bool` y el operador
   ternario en el `cout`. → [`soluciones/ej4_mayor.cpp`](soluciones/ej4_mayor.cpp)
