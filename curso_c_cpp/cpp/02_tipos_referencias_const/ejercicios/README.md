# Ejercicios — Lección 02 (C++)

1. **Nombre completo.** Pide nombre y apellido (dos `cin >>`), concaténalos con `+` y muestra el
   resultado y su longitud. → [`soluciones/ej1_nombre.cpp`](soluciones/ej1_nombre.cpp)

2. **Intercambio por referencia.** Escribe `void intercambiar(int &a, int &b)` y compruébalo.
   → [`soluciones/ej2_intercambio.cpp`](soluciones/ej2_intercambio.cpp)

3. **Contar caracteres de una frase.** Lee una línea completa con `getline` y muestra cuántos
   caracteres tiene. → [`soluciones/ej3_frase.cpp`](soluciones/ej3_frase.cpp)

4. **Reto — invertir string.** Lee una palabra y muéstrala al revés (recorre de atrás hacia
   adelante con `s[i]`, o construye una nueva). → [`soluciones/ej4_invertir.cpp`](soluciones/ej4_invertir.cpp)
