# Ejercicios — Lección 03 (C++)

1. **`maximo` sobrecargado.** Escribe `int maximo(int, int)` y `double maximo(double, double)`.
   Pruébalos. → [`soluciones/ej1_maximo.cpp`](soluciones/ej1_maximo.cpp)

2. **Saludo con valor por defecto.** `void saludar(string nombre, int veces = 1)` que imprima el
   saludo `veces` veces. → [`soluciones/ej2_saludo.cpp`](soluciones/ej2_saludo.cpp)

3. **Estadísticas por referencia.** `void stats(const vector... )` — o más simple: escribe
   `void minmax(int arr[], int n, int &min, int &max)` (con referencias, no punteros).
   → [`soluciones/ej3_minmax.cpp`](soluciones/ej3_minmax.cpp)

4. **Reto — `imprimir` sobrecargado.** Sobrecarga `imprimir` para `int`, `double` y `string`, cada
   una mostrando el tipo y el valor. → [`soluciones/ej4_imprimir.cpp`](soluciones/ej4_imprimir.cpp)
