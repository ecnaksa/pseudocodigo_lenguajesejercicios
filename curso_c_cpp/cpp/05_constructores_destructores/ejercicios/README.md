# Ejercicios — Lección 05 (C++)

1. **Fraccion.** Clase `Fraccion` con `numerador` y `denominador`, un constructor que los reciba
   (denominador 1 por defecto) y un método `valor()` que devuelva el resultado como `double`.
   → [`soluciones/ej1_fraccion.cpp`](soluciones/ej1_fraccion.cpp)

2. **CuentaBancaria con constructor.** Reescribe la cuenta de la lección 04 para que el saldo
   inicial se pase en el **constructor** (0 por defecto).
   → [`soluciones/ej2_cuenta.cpp`](soluciones/ej2_cuenta.cpp)

3. **Contador de instancias.** Clase con un miembro `static` que cuente cuántos objetos existen;
   incrementa en el constructor y **decrementa en el destructor**. Comprueba en distintos ámbitos.
   → [`soluciones/ej3_instancias.cpp`](soluciones/ej3_instancias.cpp)

4. **Reto — Libro.** Clase `Libro` con `titulo`, `autor` y `paginas`, constructor con lista de
   inicialización y un método `describir()`. → [`soluciones/ej4_libro.cpp`](soluciones/ej4_libro.cpp)
