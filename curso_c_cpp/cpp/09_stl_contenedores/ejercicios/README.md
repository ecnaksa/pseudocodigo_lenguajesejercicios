# Ejercicios — Lección 09 (C++)

1. **Promedio de un vector.** Llena un `vector<double>` con valores fijos y calcula su promedio.
   → [`soluciones/ej1_promedio.cpp`](soluciones/ej1_promedio.cpp)

2. **Frecuencia de letras.** Dada una palabra, usa un `map<char, int>` para contar cuántas veces
   aparece cada letra. → [`soluciones/ej2_frecuencia.cpp`](soluciones/ej2_frecuencia.cpp)

3. **Eliminar duplicados.** Dado un `vector<int>` con repetidos, usa un `set<int>` para obtener los
   valores únicos y muéstralos. → [`soluciones/ej3_unicos.cpp`](soluciones/ej3_unicos.cpp)

4. **Reto — agenda con map.** Usa `map<string, string>` (nombre → teléfono). Agrega tres
   contactos, muéstralos todos y busca uno por nombre.
   → [`soluciones/ej4_agenda.cpp`](soluciones/ej4_agenda.cpp)
