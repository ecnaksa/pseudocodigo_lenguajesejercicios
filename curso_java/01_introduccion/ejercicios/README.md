# Ejercicios — Lección 01

Resuélvelos **tú** antes de mirar [`soluciones/`](soluciones). Compila y ejecuta cada uno con
`javac Archivo.java && java Archivo`.

1. **Tu saludo.** Programa `Saludo` que imprima `Hola, me llamo <tu nombre>`.
   → [`soluciones/Saludo.java`](soluciones/Saludo.java)

2. **Tarjeta de presentación.** Programa `Tarjeta` que imprima en tres líneas tu nombre, tu ciudad
   y tu meta al aprender a programar. → [`soluciones/Tarjeta.java`](soluciones/Tarjeta.java)

3. **Tabla con tabulaciones.** Programa `Tabla` que, usando `\t`, imprima:
   ```
   Producto	Precio
   Cafe	3
   Pan	1
   ```
   → [`soluciones/Tabla.java`](soluciones/Tabla.java)

4. **Arte ASCII.** Programa `Cuadrado` que imprima un cuadrado de 3x3 de asteriscos.
   → [`soluciones/Cuadrado.java`](soluciones/Cuadrado.java)

5. **Reto.** Programa `Ruta` que imprima `C:\Users\ana\prog` tal cual (fíjate en las barras).
   → [`soluciones/Ruta.java`](soluciones/Ruta.java)
