# Ejercicios — Lección 02

1. **Datos personales.** Programa `Datos` con variables para tu edad (`int`), estatura en metros
   (`double`) e inicial (`char`). Imprímelas con texto.
   → [`soluciones/Datos.java`](soluciones/Datos.java)

2. **Área del círculo.** Programa `AreaCirculo` con `final double PI` y un radio fijo; calcula e
   imprime el área. → [`soluciones/AreaCirculo.java`](soluciones/AreaCirculo.java)

3. **Promedio de tres enteros.** Declara tres `int`, súmalos y calcula su promedio **con
   decimales** (cuidado con la división entera). → [`soluciones/Promedio.java`](soluciones/Promedio.java)

4. **Explorando límites.** Imprime `Integer.MAX_VALUE`, `Long.MAX_VALUE` y `Double.MAX_VALUE`.
   → [`soluciones/Limites.java`](soluciones/Limites.java)

5. **Reto — carácter y código.** Declara un `char` con `'Z'`, imprímelo como carácter y como
   número, y luego imprime el carácter cuyo código es `'Z' + 1`.
   → [`soluciones/Ascii.java`](soluciones/Ascii.java)
