# Ejercicios — Lección 03

1. **Suma de dos números.** Programa `Suma` que pida dos enteros y muestre su suma.
   → [`soluciones/Suma.java`](soluciones/Suma.java)

2. **Conversión de temperatura.** `Temperatura` que pida grados Celsius (`double`) y los muestre en
   Fahrenheit (`F = C * 9 / 5 + 32`). → [`soluciones/Temperatura.java`](soluciones/Temperatura.java)

3. **Total con formato.** `Total` que pida un precio (`double`) y una cantidad (`int`) y muestre el
   total con 2 decimales usando `printf`. → [`soluciones/Total.java`](soluciones/Total.java)

4. **Rectángulo.** `Rectangulo` que pida base y altura (enteros) y muestre área y perímetro.
   → [`soluciones/Rectangulo.java`](soluciones/Rectangulo.java)

5. **Reto — saludo personalizado.** `SaludoNombre` que pida la edad (`int`) y luego el nombre
   completo (`nextLine`), y salude. (Recuerda el `nextLine()` extra.)
   → [`soluciones/SaludoNombre.java`](soluciones/SaludoNombre.java)
