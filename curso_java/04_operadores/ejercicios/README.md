# Ejercicios — Lección 04

1. **Par o impar (residuo).** `ParResiduo` que pida un entero y muestre `n % 2`.
   → [`soluciones/ParResiduo.java`](soluciones/ParResiduo.java)

2. **Descomponer segundos.** `Segundos` que pida una cantidad de segundos y muestre cuántos minutos
   y segundos son (`/60` y `%60`). → [`soluciones/Segundos.java`](soluciones/Segundos.java)

3. **Intercambio.** `Intercambio` que pida dos enteros y los intercambie con una variable temporal;
   muéstralos antes y después. → [`soluciones/Intercambio.java`](soluciones/Intercambio.java)

4. **Evaluar condiciones.** `Condiciones` que pida una edad y muestre el valor booleano de:
   `edad >= 18`, `edad >= 18 && edad <= 65`, `edad < 12 || edad > 65`.
   → [`soluciones/Condiciones.java`](soluciones/Condiciones.java)

5. **Reto — última cifra.** `UltimaCifra` que pida un entero y muestre su última cifra (`% 10`) y el
   número sin ella (`/ 10`). → [`soluciones/UltimaCifra.java`](soluciones/UltimaCifra.java)
