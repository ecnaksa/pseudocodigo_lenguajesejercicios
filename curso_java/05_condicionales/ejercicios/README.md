# Ejercicios — Lección 05

1. **Mayor de dos.** `Mayor` que pida dos enteros y muestre el mayor (usa el ternario).
   → [`soluciones/Mayor.java`](soluciones/Mayor.java)

2. **Signo.** `Signo` que pida un entero y diga si es positivo, negativo o cero.
   → [`soluciones/Signo.java`](soluciones/Signo.java)

3. **Año bisiesto.** `Bisiesto` que pida un año y diga si es bisiesto (divisible entre 4 y no entre
   100, **o** divisible entre 400). → [`soluciones/Bisiesto.java`](soluciones/Bisiesto.java)

4. **Menú con switch.** `Menu` que pida una opción (1-3) y con `switch` de expresión devuelva el
   texto de la acción. → [`soluciones/Menu.java`](soluciones/Menu.java)

5. **Reto — calculadora.** `Calculadora` que pida dos números y un operador (`+ - * /`) y muestre el
   resultado con `switch`. Cuida la división entre 0.
   → [`soluciones/Calculadora.java`](soluciones/Calculadora.java)
