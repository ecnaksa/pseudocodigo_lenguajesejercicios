# Ejercicios — Lección 06

1. **Cuenta regresiva.** `Regresiva` que pida `n` y cuente de `n` a 1, luego imprima `Despegue!`.
   → [`soluciones/Regresiva.java`](soluciones/Regresiva.java)

2. **Suma de 1 a N.** `SumaN` que pida `N` y calcule `1 + 2 + ... + N`.
   → [`soluciones/SumaN.java`](soluciones/SumaN.java)

3. **Tabla de multiplicar.** `TablaMul` que pida un número y muestre su tabla del 1 al 10.
   → [`soluciones/TablaMul.java`](soluciones/TablaMul.java)

4. **Factorial.** `Factorial` que pida `n` y calcule `n!` (usa `long`).
   → [`soluciones/Factorial.java`](soluciones/Factorial.java)

5. **Reto — pirámide.** `Piramide` que pida una altura `h` e imprima una pirámide de asteriscos
   (`*`, `**`, `***`...). → [`soluciones/Piramide.java`](soluciones/Piramide.java)
