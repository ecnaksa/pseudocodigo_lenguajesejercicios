# Ejercicios — Lección 07

1. **Cuadrado.** Método `static int cuadrado(int n)` que devuelva `n*n`; úsalo en un bucle para los
   cuadrados del 1 al 5. → [`soluciones/Cuadrado.java`](soluciones/Cuadrado.java)

2. **Máximo de tres.** `static int maximo3(int a, int b, int c)`.
   → [`soluciones/Maximo3.java`](soluciones/Maximo3.java)

3. **¿Es primo?** `static boolean esPrimo(int n)`; lista los primos del 2 al 30.
   → [`soluciones/Primo.java`](soluciones/Primo.java)

4. **Conversor.** `static double aFahrenheit(double c)`; imprime una tabla de 0, 10, 20, 30 y 40 °C.
   → [`soluciones/Conversor.java`](soluciones/Conversor.java)

5. **Reto — potencia recursiva.** `static long potencia(int base, int exp)` con recursión (caso
   base `exp == 0`). → [`soluciones/Potencia.java`](soluciones/Potencia.java)
