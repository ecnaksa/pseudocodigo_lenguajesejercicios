# Ejercicios — Lección 08

1. **Máximo y mínimo.** `MaxMin` con un arreglo de 6 enteros fijos; muestra su máximo y mínimo.
   → [`soluciones/MaxMin.java`](soluciones/MaxMin.java)

2. **Invertir.** `Invertir` que lea 5 enteros en un arreglo y lo muestre al revés.
   → [`soluciones/Invertir.java`](soluciones/Invertir.java)

3. **Promedio con método.** `PromedioArr` con `static double promedio(int[] arr)` y un arreglo de
   ejemplo. → [`soluciones/PromedioArr.java`](soluciones/PromedioArr.java)

4. **Ordenar y mostrar.** `Ordenar` que ordene un arreglo con `Arrays.sort` y lo imprima con
   `Arrays.toString`. → [`soluciones/Ordenar.java`](soluciones/Ordenar.java)

5. **Reto — contar mayores al promedio.** `Mayores` que, dado un arreglo, calcule su promedio y
   cuente cuántos elementos lo superan. → [`soluciones/Mayores.java`](soluciones/Mayores.java)
