# Ejercicios — Lección 09

1. **Contar vocales.** `Vocales` que lea una palabra y cuente sus vocales (recórrela con `charAt`).
   → [`soluciones/Vocales.java`](soluciones/Vocales.java)

2. **¿Palíndromo?** `Palindromo` que lea una palabra y diga si se lee igual al derecho y al revés
   (compara `charAt(i)` con `charAt(largo-1-i)`). → [`soluciones/Palindromo.java`](soluciones/Palindromo.java)

3. **Iniciales.** `Iniciales` que lea un nombre completo (con `nextLine`), lo divida con `split(" ")`
   y muestre la inicial de cada palabra. → [`soluciones/Iniciales.java`](soluciones/Iniciales.java)

4. **Reto — invertir con StringBuilder.** `InvertirSB` que lea una frase y la muestre al revés
   usando `StringBuilder.reverse()`. → [`soluciones/InvertirSB.java`](soluciones/InvertirSB.java)
