# Ejercicios — Lección 10

Cada clase incluye un `main` para probarla (compila y ejecuta con `javac X.java && java X`).

1. **Circulo.** Clase `Circulo` con atributo `radio` y métodos `area()` y `circunferencia()`.
   → [`soluciones/Circulo.java`](soluciones/Circulo.java)

2. **Contador.** Clase `Contador` con atributo `private int valor` y métodos `incrementar()`,
   `reiniciar()` y `obtener()`. → [`soluciones/Contador.java`](soluciones/Contador.java)

3. **Persona.** Clase `Persona` con `nombre` y `edad` privados y getters/setters (el `setEdad` no
   acepta negativos). → [`soluciones/Persona.java`](soluciones/Persona.java)

4. **Reto — Termometro.** Clase `Termometro` con `private double celsius`, `set(double)`,
   `getCelsius()` y `getFahrenheit()`. → [`soluciones/Termometro.java`](soluciones/Termometro.java)
