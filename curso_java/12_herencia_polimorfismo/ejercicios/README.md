# Ejercicios — Lección 12

Pon todas las clases en un archivo con el `main` en la clase pública (como en los ejemplos).

1. **Empleado y Gerente.** Base `Empleado` (con `salario()` que devuelve un básico) y `Gerente` que
   redefina `salario()` sumando un bono. → [`soluciones/Empleados.java`](soluciones/Empleados.java)

2. **Formas abstractas.** Clase abstracta `Forma` con `abstract double area()` y derivadas
   `Cuadrado` y `Triangulo`; recórrelas polimórficamente.
   → [`soluciones/Formas.java`](soluciones/Formas.java)

3. **Reto — Vehículos.** Base `Vehiculo` con método `describir()`; derivadas `Coche` y `Moto` que lo
   redefinan. → [`soluciones/Vehiculos.java`](soluciones/Vehiculos.java)
