# Ejercicios — Lección 14

1. **Lista de compras.** `ListaCompras` que use un `ArrayList<String>`: agrega 4 productos, quita
   uno y muestra la lista final ordenada. → [`soluciones/ListaCompras.java`](soluciones/ListaCompras.java)

2. **Frecuencia de palabras.** `Frecuencia` que, dada una frase, cuente cuántas veces aparece cada
   palabra usando un `HashMap<String,Integer>`.
   → [`soluciones/Frecuencia.java`](soluciones/Frecuencia.java)

3. **Eliminar duplicados.** `Unicos` que, dado un arreglo de enteros con repetidos, use un
   `HashSet` para obtener los únicos. → [`soluciones/Unicos.java`](soluciones/Unicos.java)

4. **Reto — agenda con Map.** `Agenda` que use `HashMap<String,String>` (nombre → teléfono): agrega
   tres contactos, muéstralos y busca uno. → [`soluciones/Agenda.java`](soluciones/Agenda.java)
