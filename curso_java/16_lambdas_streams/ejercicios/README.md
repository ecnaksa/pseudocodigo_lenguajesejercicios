# Ejercicios — Lección 16

1. **Filtrar pares.** `FiltrarPares` que, dada una `List<Integer>`, use un stream para quedarse con
   los pares y mostrarlos. → [`soluciones/FiltrarPares.java`](soluciones/FiltrarPares.java)

2. **Contar aprobados.** `Aprobados` que, dada una lista de notas, cuente cuántas son ≥ 60 con
   `filter` + `count`. → [`soluciones/Aprobados.java`](soluciones/Aprobados.java)

3. **Mayúsculas.** `Mayusculas` que, dada una lista de nombres, use `map` para pasarlos a mayúsculas
   y recolectarlos en una nueva lista. → [`soluciones/Mayusculas.java`](soluciones/Mayusculas.java)

4. **Reto — promedio con streams.** `PromedioStream` que calcule el promedio de una `List<Integer>`
   usando `mapToInt` y `average`. → [`soluciones/PromedioStream.java`](soluciones/PromedioStream.java)
