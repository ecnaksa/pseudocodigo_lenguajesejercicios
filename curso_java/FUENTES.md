# Fuentes y bibliografía (Java)

Este curso se apoya en material de referencia reconocido. **Nada de este curso copia texto de
esas obras**: son explicaciones propias; las fuentes se citan como referencia y lectura ampliada.

## Libros

- **Schildt, H. — *Java: The Complete Reference* (12.ª ed., 2021).**
  Referencia completísima del lenguaje y la biblioteca estándar. Buena como consulta.
- **Sierra, K. & Bates, B. — *Head First Java* (3.ª ed., 2022).**
  Enfoque visual y muy didáctico para principiantes. Excelente primer libro.
- **Bloch, J. — *Effective Java* (3.ª ed., 2018).**
  El libro de **buenas prácticas** de Java, escrito por uno de los diseñadores de la biblioteca
  estándar. Para cuando ya domines lo básico: te enseña a escribir Java *bien*.
- **Horstmann, C. — *Core Java, Vol. I – Fundamentals* (12.ª ed.).**
  Referencia sólida y actualizada, orientada a fundamentos.
- **Deitel, P. & Deitel, H. — *Java How to Program*.** Muy usado en cursos universitarios, con
  muchos ejemplos.

## Documentación y sitios web

- **Documentación oficial de Oracle** — https://docs.oracle.com/en/java/
  - **The Java Tutorials** (gratuito, muy completo): https://docs.oracle.com/javase/tutorial/
  - **API de la biblioteca estándar** (referencia de todas las clases):
    https://docs.oracle.com/en/java/javase/21/docs/api/
- **Baeldung** — https://www.baeldung.com/ Tutoriales prácticos de Java y su ecosistema, muy
  claros. Consulta frecuente.
- **Jenkov Tutorials** — https://jenkov.com/tutorials/java/index.html Explicaciones detalladas de
  temas del núcleo del lenguaje.
- **W3Schools Java** — https://www.w3schools.com/java/ Introducción rápida con ejemplos simples.
- **GeeksforGeeks — Java** — https://www.geeksforgeeks.org/java/ Artículos y ejemplos por tema.
- **dev.java** — https://dev.java/ Sitio oficial de la comunidad Java, con guías modernas.

## Herramientas

- **JDK** (Temurin/Adoptium) — https://adoptium.net/
- **IntelliJ IDEA** — https://www.jetbrains.com/idea/ · **VS Code** — https://code.visualstudio.com/
- **Maven** (https://maven.apache.org/) y **Gradle** (https://gradle.org/) — sistemas de
  construcción y gestión de dependencias para proyectos Java grandes.
- **JUnit** — https://junit.org/ — el framework estándar para pruebas automáticas.

## Especificaciones oficiales (referencia exacta)

- **Java Language Specification (JLS)** — la definición formal del lenguaje:
  https://docs.oracle.com/javase/specs/
- **Versiones LTS** (soporte a largo plazo): Java 8, 11, **17**, **21**. Este curso usa Java 17+
  (probado con el JDK 21).

## Cómo se citan las fuentes en las lecciones

Al final de cada lección hay una sección **"Para profundizar"** que apunta a los capítulos o
páginas concretas relacionados con el tema. Úsalas cuando quieras ir más allá de lo que el curso
explica. La **documentación oficial de Oracle** y **Baeldung** son las referencias que más se
citan.
